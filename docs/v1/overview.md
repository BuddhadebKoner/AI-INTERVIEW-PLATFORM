# AI Interview Platform - Project Overview

## 🎯 Project Vision
An intelligent interview platform that combines AI-powered question generation, real-time video monitoring, and voice transcription to create a comprehensive interview experience.

## 🏗️ Architecture Summary
- **Frontend**: React + Vite + TailwindCSS (Vercel)
- **Main Server**: Node.js + Express (Railway/Render)
- **AI Service**: Python + FastAPI + Gemini API (Railway/Render)
- **Video Service**: Python + OpenCV + Flask (Railway/Render)
- **Database**: MongoDB Atlas (Free tier)
- **Authentication**: Clerk (Free tier)

## 🚀 Key Features
1. **Smart Resume Analysis** - PDF parsing and skill extraction
2. **Dynamic Question Generation** - AI-powered questions based on tech stack
3. **Real-time Video Monitoring** - Face detection, attention tracking
4. **Voice Transcription** - Live speech-to-text conversion
5. **Intelligent Evaluation** - AI-powered response analysis
6. **Comprehensive Feedback** - Detailed performance reports

## 💰 Cost Estimate: $0/month
All services use free tiers with sufficient limits for a project/portfolio demonstration.

## 📁 Quick Start
1. Clone repository
2. Set up environment variables

4. Run development servers
